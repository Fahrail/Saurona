Feature Guide

Server Systems

01

Quick Start

Saurona Server-Side is a dedicated-server Fabric mod. Build the jar, place it in the server mods folder, restart once, then edit the generated world files.

Build jar .\gradlew.bat build build/libs/server-side-1.0.0.jar
Main config world/server-side-config.json /ss reload /serverside reload

Reload requires OP level 4. Restarting is safest after adding a new jar or after large manual data edits.

Permissions

  • OP 4: owner tools, config reload, staff roles, view distance, full admin.
  • OP 3: admin moderation and gamemode access.
  • OP 2: utility access such as teleport, fly, staff chat, and collectibles.
  • Staff roles can grant access without giving full OP.

Data Files

  • world/server-side-bank.json
  • world/server-side-backpacks.json
  • world/server-side-factions.json
  • world/server-side-staff-roles.json
  • world/server-side-playstyles.json
  • world/server-side-weekly-challenges.json
  • world/server-side-bounties.json
  • world/server-side-recipes.json
02

Prefixes

Prefixes are controlled from server-side-config.json. Chat display order is playstyle first, then main prefix, then faction leader tag.

Order [H]/[M] - staff/faction/Wanderer - [L] - name
Tab List Only the main prefix shows. Staff can be sorted near the top.
Bracket Style Gray brackets with colored role text.

Staff Roles

  • Owner: #5E4B8B, OP 4.
  • Manager: #C89B4A, OP 4.
  • Admin: #4C6FB3, OP 3.
  • Mod: #B65F7A, moderation, fly, teleport.
  • Advisor: #B8734F, prefix only.
  • Guide: #718C5A, prefix only.
/staff add <player> <role> /staff remove <player>

Faction Prefixes

Faction colors are unique hex values in the config so they can match the Discord roles.

Wanderer is the default join prefix and uses #91B2D1.

03

Haven And Mortal

Haven is the default playstyle. Mortal is a permanent opt-in with a clear warning and clickable confirmation.

Haven [H]

PvP protected against other players, keep inventory enabled, and excluded from hunts or bounties.

#6F8FAF

Mortal [M]

PvP enabled with other Mortals, inventory drops on death, and eligible for bounties.

#C47A45
/playstyle /playstyle mortal /playstyle reset <player> <haven|mortal>
04

Factions And Homes

Faction homes are stored by faction, not by leader, so leadership changes do not move the home. Teleport warmup, cooldown, movement cancel, damage cancel, sounds, particles, and messages are configurable.

/faction join <faction> /faction leave /faction info [faction] [page] /faction home /faction sethome /faction homeinfo /faction clearhome /factionadmin sethome <faction> /factionadmin clearhome <faction> /factionadmin homeinfo <faction>

Use /faction info for your own faction, or /faction info <faction> to inspect another faction when allowed.

Economy And Bank

Coins are item-based and can be deposited into a player bank. Withdraw aliases are available for faster use.

/bank /balance /deposit all /dep all /withdraw <amount> /wdraw <amount>

Backpacks

Players start at 1 row and can progress to 6 rows. Player coin upgrades are removed; backpack upgrades come from playtime rewards or staff commands.

/backpack /bp /backpackadmin upgrade <player> /backpackadmin downgrade <player>
05

Timed Rewards And AFK

Playtime rewards are configurable and skip AFK time. Rewards do not use coins by default and can grant items, XP, backpack upgrades, extra homes, abilities, and one-time reward items.

  • Every 10 hours up to 100 hours.
  • Every 25 hours from 100 to 200 hours.
  • Every 50 hours after 200 hours.
  • /craft unlocks at 10 hours; staff can use it for free.
/playtime /craft /ct /afk /stats

Spawn Items

Players need the Starlight Phial and Middle-earth Map while leaving spawn. Missing items are replaced without duplicating items being moved between inventory and backpack.

  • middle-earth:starlight_phial
  • middle-earth:middle_earth_map
06

Weekly Challenges

Weekly challenges track server-wide objectives with player progress persisted across restarts. Challenge names are objective-based so players can quickly tell what to do.

Types Travel, break, mine, chop, harvest, kill, place, and playtime.
Reset Configurable day, time, and timezone. Default timezone can be America/Chicago.
Bonus Completing all weekly challenges can grant an extra completion reward.
/challenges /challenges page <page>
07

Bounties And Trophy Ability

Bounties are Mortal-only. A Mortal can place a coin bounty on another Mortal, and an eligible Mortal killer can claim the reward.

/bounty place <player> <amount> /bounty list /bounty view <player> /ability /abilityadmin item trophy /abilityadmin grant <player> <ability> /abilityadmin apply <ability> /abilityadmin remove

The trophy ability can be applied to eligible weapons and has a configurable player-head drop chance.

08

Custom Recipe Manager

Recipes can be disabled by ID from an editable data file. Disabled recipes are automatically reapplied on startup and every recipe/datapack reload.

Data file world/server-side-recipes.json
/recipes list /recipes disable <recipe> /recipes enable <recipe> /recipes reload

The reload logic logs how many configured recipes were disabled and safely skips missing recipe IDs.

09

Custom NPC Traders

Staff can turn explicitly selected vanilla or Middle-earth NPC entities into persistent custom traders while keeping their normal appearance. Right-click opens the vanilla merchant screen.

/trader create <id> /trader remove <id> /trader list /trader info <id> /trader title <id> <title> /trader trade add <id> <buy> <count> <sell> <count> /trader trade clear <id> /trader reload

Moderation

/mute /tempmute /unmute /jail /tempjail /unjail /kick /possiblealts <player>

Staff Utility

/fly /flyadmin give <player> /flyadmin blacklist <player> /gm <0|1|2|3|4> /vanish /silentjoin /viewdistance <distance> /unbreakable

Protection Tools

Spawn protection, blacklisted items, chat filters, and welcome rewards are configurable for launch control.

/blacklistitem add /blacklistitem remove /blacklistitem list /welcome enable /welcome disable /ss reload
10

Discord Integration

The bot syncs faction, Wanderer, Haven, and Mortal roles, handles account linking, and bridges cleaned Minecraft death/chat messages.

  • Haven is automatically applied unless a player opts into Mortal.
  • Faction role changes remove Wanderer.
  • Linking uses the Discord slash command flow and blocks progression until linked or staff-verified.
  • Death bridge messages are formatted for cleaner Discord output.
11

Launch Setup Checklist

  • Build and upload the latest server-side jar.
  • Start the server once so all data files generate.
  • Edit server-side-config.json for prefixes, colors, timings, rewards, messages, blocked words, and Discord role IDs.
  • Set faction homes with /factionadmin sethome <faction>.
  • Disable blocked recipes with /recipes disable <recipe>, then confirm /recipes reload.
  • Prepare custom traders and verify their trades after restart.
  • Disable launch welcome rewards until ready with /welcome disable.
  • Run /ss reload after config edits and restart after jar changes.
